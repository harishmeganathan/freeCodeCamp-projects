Web Development

The process of building, coding, and maintaining websites and web applications that run online.

Front-End Development

HTML - structure, CSS - styling, and JavaScript - interactivity, along with frameworks like React or Vue.

Back-End Development

Back-End Development - Server-Side: Manages the hidden infrastructure, databases, user authentication, and server logic. Common languages and environments include Node.js/JavaScript, Python, PHP, and databases like SQL or MongoDB.

Full-Stack Web Development

Combines both front-end and back-end responsibilities.
